Google Sheets 自动收集成绩配置教程

只需配置一次，后续学生交卷成绩全自动写入您的私密表格

← 返回生成器
步骤 1 新建 Google Sheet 并打开代码编辑器
  1. 登录您的 Google 账号，进入 Google Drive 新建一个空白的 Google Sheets（电子表格），命名为例如“连词成句成绩汇总”。
  2. 点击顶部菜单栏的 扩展程序 (Extensions) → Apps Script。
步骤 2 粘贴接收脚本

清空编辑器中原有的默认代码，将以下代码完整复制并粘贴进去：

function doGet(e) {
  return handle(e);
}

function doPost(e) {
  return handle(e);
}

function handle(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);

  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheets()[0];
    
    var p = {};
    if (e && e.parameter && Object.keys(e.parameter).length > 0) {
      p = e.parameter;
    } else if (e && e.postData && e.postData.contents) {
      try {
        p = JSON.parse(e.postData.contents);
      } catch (err) {
        p = e.parameter || {};
      }
    }
    
    // 如果首行为空，自动初始化表头
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["提交时间", "学生姓名", "总题数", "正确题数", "用时(秒)", "正确率"]);
    }
    
    // 写入学生成绩
    sheet.appendRow([
      p.time || new Date().toLocaleString(),
      p.student || "未填姓名",
      p.total || 0,
      p.correct || 0,
      p.duration || 0,
      p.accuracy || "0%"
    ]);
    
    return ContentService.createTextOutput("SUCCESS");
  } catch (err) {
    return ContentService.createTextOutput("ERROR: " + err.toString());
  } finally {
    lock.releaseLock();
  }
}

// 专门用于触发 Google 授权弹窗的函数
function triggerAuth() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  sheet.appendRow(["授权成功", new Date().toLocaleString()]);
}

粘贴后，点击上方工具栏的 保存 (软盘图标)。

步骤 3 执行一次授权（关键必须操作）
  1. 在 Apps Script 上方工具栏，找到“调试”按钮左侧的函数下拉框。
  2. 点击下拉框，选中 triggerAuth。
  3. 点击旁边的 运行 (Run) 按钮。
  4. 此时屏幕中央会弹出 “需要授权 (Authorization required)”：
    • 点击 查看权限 (Review permissions) 并选择您的 Google 账号。
    • 如果出现“Google 尚未验证此应用”，点击左下角小灰字 高级 (Advanced)。
    • 点击最下方的 前往“未命名项目”（不安全） / Go to Untitled project (unsafe)。
    • 点击 允许 (Allow)。
💡 提示： 授权成功后切回 Google Sheet 表格，若看到多出了一行“授权成功”，说明写入权限已彻底打通（您可以手动删掉这行测试记录）。
步骤 4 发布为 Web 应用并获取链接
  1. 点击右上角蓝色的 部署 (Deploy) → 新建部署 (New deployment)。
  2. 在弹窗左侧点击齿轮图标，选择 Web 应用 (Web app)。
  3. 填写与确认配置项（极重要）：
    • 说明：成绩收集
    • 执行身份 (Execute as)：选择 我 (Me)
    • 谁有权访问 (Who has access)：选择 任何人 (Anyone) （注：这样学生在自己设备上交卷时才无需登录您的 Google 账号）
  4. 点击 部署 (Deploy)。
  5. 复制生成的 Web 应用程序网址 (Web app URL)（网址必须以 /exec 结尾）。
步骤 5 粘贴至教师端生成器

回到教师端后台（admin.html），把刚刚复制的链接粘贴到 第 3 项“你的 Google Sheets 成绩接收链接” 输入框中即可！
